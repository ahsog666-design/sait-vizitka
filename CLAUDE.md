# Сайт-визитка Георгия Ермакова

Сайт ведущего мероприятий (Казахстан). Простой статический сайт: `index.html`, `style.css`, `script.js`, без фреймворков и сборки.

## Общение
- Георгий часто пишет из Telegram, в том числе голосовыми. Отвечать по-русски, просто, без технического жаргона.
- Голосовые расшифровывать: `ffmpeg -i файл.oga -ar 16000 -ac 1 voice.wav`, затем `whisper-cli -m ~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin -l ru -nt -f voice.wav`.
- Если просьба двусмысленная, лучше коротко уточнить с вариантами (1, 2), чем угадывать.
- Тексты на сайте на русском. Названия проектов во вкладках латиницей, каждое слово с большой буквы (Tram in the Raive, Teambuilding).

## Раздел «Мои работы» (проекты и видео)
- Список проектов и видео — массив `projects` в начале `script.js`.
- Видео из Instagram по ссылке:
  1. `yt-dlp -f "mp4/bestvideo*+bestaudio/best" --merge-output-format mp4 -o "videos/<имя>.%(ext)s" "<ссылка без ?hvrq=...>"`
  2. Обложка — кадр с 1-й секунды: `ffmpeg -y -ss 1 -i videos/<имя>.mp4 -frames:v 1 -q:v 4 videos/<имя>.jpg`
  3. Строка в `videos` проекта: `{ url: "videos/<имя>.mp4", poster: "videos/<имя>.jpg", vertical: true }` (рилсы вертикальные).
- Имена файлов: `<проект>-N`, например `tram-raive-2.mp4`, `tram-raive-3.mp4`.
- Проект только из своих видеофайлов показывается 3D-лентой (`renderCurve`). Проект с `albums` показывает папки с фото и видео карточками рядом.
- Пробовали делать видео в Tram in the Raive круглыми «сторис» — Георгию не понравилось, откатили. Оставляем карточки.

## Публикация
- Сайт: https://georgiy-ermakov.vercel.app (Vercel, проект `sait-vizitka`; домен закреплён за проектом). Старый адрес sait-vizitka-pearl.vercel.app тоже работает.
- Vercel не подключён к git, выкладка вручную: `vercel --prod --yes`.
- Код также в GitHub (`main`) и на GitHub Pages: коммит, затем `git push origin main`.
- После выкладки проверять curl-ом, что страница и новые файлы отдаются.
- Если Георгий не видит изменений — скорее всего кэш браузера: обновить с Cmd + Shift + R.
